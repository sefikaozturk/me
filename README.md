# sefikaozturk.com

Plain HTML and one `style.css`. No build step.

**Edit:** `node edit.js`, open http://localhost:4321, press `E` (or click Edit), type, then `⌘S`. Changes save straight into the HTML files. Drop or paste images (saved to `assets/uploads/`), paste links, start a line with `- `, `1. ` or `# ` for lists and headings.

**Publish:** `git add -A && git commit -m "update" && git push`. Vercel deploys main.

Link-only pages (keep out of nav and `llms.txt`): `/intersections`, `/cv-59579bab`.

External links open in a new tab; `edit.js` adds that automatically when you save.
